Nations

Each AI has its own personality. Tick Live to let the real model (via your API key) set its nation's strategy every ~90 game-seconds; the built-in general carries it out.

AI Keys & Models

Keys are sent only to the local game server (node server.mjs), which calls the provider. You can also set them as environment variables (e.g. OPENAI_API_KEY, ANTHROPIC_API_KEY, XAI_API_KEY, GEMINI_API_KEY). Without a key a nation is played by its built-in personality.

Models per AI (provider · model · price $ per million tokens in / out, for the cost analytics)

Replays

Every battle you watch is saved here when it ends or when you leave it (the last 12). A replay is the battle's seed and setup plus the orders the live models gave, so it plays out exactly the same again.

Tournament

Plays many battles in the background between the built-in AI personalities and keeps an Elo rating for each. Battles run at full speed in Web Workers; nothing is drawn. Live API models are not used here, so a tournament costs nothing.
